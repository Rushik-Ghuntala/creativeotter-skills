# Image requests and creative review

CreativeOtter adaptation, 2026-11-06. Follow [the runtime contract](../runtime-contract.md).

An explicit image request proceeds through the current quote and single execution flow without an extra browser approval. Estimate-only and planning-only requests never execute. Honor the requested count and budget, existing consent and any explicit creative review stage. An avatar's canonical-image approval is distinct from generation authorization. Video/audio execution is unavailable; do not invent review cards or use an image quote for it.
