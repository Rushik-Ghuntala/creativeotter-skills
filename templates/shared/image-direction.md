# Image direction

CreativeOtter adaptation, 2026-11-06. This is creative guidance; use the live tool schema and quote for execution.

Resolve purpose, subject, composition, required copy, reference roles and what must remain unchanged. Ask only for consequential missing information. Social posts often need a readable headline, a clear focal subject and safe margins. Preserve exact supplied text; do not invent product claims or a different logo.

For a reference edit, describe the smallest requested change and preserve unrelated elements. State which reference anchors the subject, product, identity or style; pass the corresponding owned image IDs in that same order. For product sets repeat stable geometry, label, colors and materials. Check delivered outputs for those details, readable copy and crop safety. Offer another paid take only when the user requests it.

The provider accepts prompt, aspect_ratio (1:1, 4:5, 16:9, 9:16), resolution 1K and up to 14 distinct reference_asset_ids. Quote one image at a time. Do not add image_url, extras, num_images, duration, video/audio fields or parameters from an inherited guide. Native image tools have separate schemas; only use options actually supported by that host. Transparency, exact pixel dimensions, perfect text or identical characters are not guarantees of the provider schema.

A request for several images is a set of supported image jobs, followed by the saved branded gallery. Do not generate an extra hero, contact sheet or slide merely to display results. Existing-image display is a read operation.
