# Plan advertisement variations

CreativeOtter adaptation, 2026-11-06. Follow [the runtime contract](references/runtime-contract.md).

Write the requested number of variations with a short name, hook, spoken line and visual direction. Keep the product facts, required copy and disclosures consistent. Change the requested variable, such as hook angle or voice direction. Preserve an existing script when it must stay fixed.

Video generation, new audio, captioning and clip assembly are not available. Explain that for a request to render variations; do not submit image quotes or call inherited video tools. Planning and rewriting do not create charges or finished files.

If the user explicitly requests image-ad variations, use the product-photoshoot image workflow for that requested count instead. Do not silently convert a video request into paid images. A saved project brief is optional only when requested; `manage_projects` does not render a batch.
