# Skill inventory

All 21 adapted skills match the implemented image and Studio tools. Motion graphics use the opt-in HyperFrames renderer when configured; filmed video and generated audio/editing skills support preparation only. Installing skills does not enable a worker, pricing or generation. Current native and provider image work both require the live credit workflow. The original copied snapshot remains unchanged outside active packages.

| Skill | Purpose |
| --- | --- |
| `creativeotter` | Use CreativeOtter for image creation, saved images, brand kits, characters, account questions and creative project planning. Route a specific media request to its focused skill. |
| `creativeotter-ad-variations` | Develop alternative ad hooks, scripts and shot plans. CreativeOtter video ad generation, voice replacement and caption rendering are not implemented. |
| `creativeotter-budget-projects` | Group CreativeOtter saved images by client or project and read original attributed credit costs. Budget targets are planning targets, not automatic spending caps. |
| `creativeotter-build-film` | Plan a multi-shot CreativeOtter film with script, continuity and storyboard. Footage, speech, audio mixing and final assembly are not implemented. |
| `creativeotter-clone-voice` | Explain what is needed for an authorized voice-cloning project. CreativeOtter voice cloning and audio upload are not implemented; do not collect recordings for this workflow. |
| `creativeotter-create-avatar` | Create an avatar or character sheet using CreativeOtter image generation, then save its approved image as a reusable character. Voice and talking-video generation are not available. |
| `creativeotter-create-character` | Save, inspect or update an existing CreativeOtter character and its ready reference image. Use create-avatar to generate a new identity sheet. |
| `creativeotter-create-reels` | Suggest Reel or short-video cuts from supplied footage or a transcript. CreativeOtter transcription, video cutting, reframing and subtitle rendering are not implemented. |
| `creativeotter-create-ugc-ad` | Write a creator-style product ad script and shot plan. CreativeOtter presenter video, speech, lip-sync and assembled UGC production are not implemented. |
| `creativeotter-edit-media` | Explain or draft cuts, captions, framing, audio and assembly edits for existing media. CreativeOtter video/audio processing is not implemented; image edits use generate-image. |
| `creativeotter-generate-image` | Create or edit one image through CreativeOtter, using a suitable native image tool or the available provider model. Use for social posts, ads, illustrations and image corrections. |
| `creativeotter-generate-music` | Write music briefs or lyrics and save them in CreativeOtter. Music generation, remixing and audio downloads are not implemented. |
| `creativeotter-generate-sound-effects` | Write sound-effect and ambience briefs for CreativeOtter. Sound-effect generation and audio rendering are not currently implemented. |
| `creativeotter-generate-video` | Develop a single video clip concept, prompt or animation plan. CreativeOtter video generation, extensions, lip-sync and source transformations are not implemented. |
| `creativeotter-generate-voiceover` | Prepare narration, dialogue and reusable voice direction for CreativeOtter. Speech generation and synthetic voice design are not yet implemented. |
| `creativeotter-plan-video` | Write a video brief, script and ordered shot list, and save a CreativeOtter film storyboard when requested. This workflow does not generate footage or speech. |
| `creativeotter-product-photoshoot` | Create a coordinated set of product images or carousel slides through the supported CreativeOtter image workflow, reusing product and brand references. |
| `creativeotter-render-html` | Create and revise motion-graphics videos with animated typography, shapes, transitions and logo reveals. Use for animated graphic designs, not still images or filmed footage. |
| `creativeotter-setup` | Help users connect CreativeOtter and discover its currently enabled image, library and planning features. A setup request does not authorize paid samples. |
| `creativeotter-submit-feedback` | Draft a CreativeOtter product or media-quality report when explicitly requested. Direct feedback submission is not implemented. |
| `creativeotter-swap-characters` | Prepare an authorized character-replacement brief for an existing video. CreativeOtter face swaps, character recasting and motion transfer are not implemented. |
