# Skill inventory

All 21 workflows are included in both client packages. Their execution depends on enabled tools on our own backend; this repository alone performs no media generation.

| Skill | Purpose |
| --- | --- |
| `creativeotter` | Route mixed media and workspace requests through CreativeOtter. Use for several media types, onboarding, account activity, saved assets, themes or budgets; use a focused skill for one clear media outcome. |
| `creativeotter-ad-variations` | Turn one product shot, one model or one existing ad into a numbered set of video ad variations: each variation is generated with its own hook visuals and line, or gets a new generated opening spliced onto the existing ad, or (cheapest) keeps the same footage with a new voiceover or captions. One estimate for the set. Use for hook tests, A/B ad variants for Meta, Instagram or TikTok, or 'N versions of my ad'. |
| `creativeotter-budget-projects` | Organize CreativeOtter generation costs by client or production using enabled budget-project tools. Use to assign work, inspect spend or manage a stated production budget. |
| `creativeotter-build-film` | Produce a complete multi-shot CreativeOtter film from planning through an assembled first cut. Use for ads, explainers, music videos, or stories that require several coordinated clips, narration, and approval gates. |
| `creativeotter-clone-voice` | Guide private recording upload, consented voice cloning and reuse through enabled CreativeOtter providers. Use for copying a real speaker with explicit permission; use generate-voiceover to design a new synthetic voice. |
| `creativeotter-create-avatar` | Create a reusable personal avatar or fictional Character from photos or a brief, generate and approve a consistent character sheet, save it in Characters, and optionally give it a voice (designed, cloned with consent, or stock). |
| `creativeotter-create-character` | Save, inspect or update an existing reusable CreativeOtter Character and its visual identity. Use creativeotter-create-avatar for guided photo-to-avatar and character-sheet creation. |
| `creativeotter-create-reels` | Turn existing long-form video into coherent social clips in the requested aspect ratio, with optional captions. Use when the agent should transcribe, select standalone highlights, choose speech-safe cuts and framing, then render and review. User-selected moments override AI selection; invented footage belongs to video-generation skills. |
| `creativeotter-create-ugc-ad` | Create a scripted creator-style UGC product ad with CreativeOtter. Use when the user wants a vertical testimonial, demo, unboxing, problem-solution ad, or social video combining a creator, product, speech, and several shots. |
| `creativeotter-edit-media` | Edit existing video or audio with CreativeOtter without regenerating it: trim, cut and reorder chosen moments, resize or reframe, caption, transcribe, clean speech, extract frames, add or mix audio, burn a logo watermark, compose images and clips, or add an intro/outro. Use when the source footage should be kept; use generation skills for invented or transformed footage and create-reels to pick highlights. |
| `creativeotter-generate-image` | Generate or edit one image through CreativeOtter using an enabled model. Use for a single image or correction; use product-photoshoot for coordinated campaigns or create-avatar for a reusable identity. |
| `creativeotter-generate-music` | Compose songs, scores, instrumentals or remixes through enabled CreativeOtter music models. Use for music, not narration or isolated sound effects. |
| `creativeotter-generate-sound-effects` | Generate sound effects, Foley, ambience, loops, UI cues, transitions, impacts, or audio textures with ElevenLabs Sound Effects v2 through CreativeOtter. Use for non-speech, non-song audio. |
| `creativeotter-generate-video` | Generate, animate, extend, reframe, or transform one video clip with CreativeOtter. Use for a clear single-clip request when the user has not asked for a storyboard, UGC ad, or complete multi-shot film. |
| `creativeotter-generate-voiceover` | Generate narration, dialogue, or expressive speech with CreativeOtter, or design a new custom synthetic voice from a description. Use for spoken audio, voice selection, a saved Character voice, or 'make me a new voice'. To copy a real person's voice from a recording, use creativeotter-clone-voice. |
| `creativeotter-plan-video` | Plan a video as an approved script, shot list, and storyboard with clean generation references. Use before costly multi-shot work, when continuity matters, or when the user asks to storyboard without producing a final film yet. |
| `creativeotter-product-photoshoot` | Create a coherent set of campaign-ready product images with CreativeOtter. Use for packshots, ecommerce sets, lifestyle scenes, launch campaigns, or several images that must preserve the same product and brand. |
| `creativeotter-render-html` | Render HTML/CSS to an image or an HTML/HyperFrames motion composition through enabled CreativeOtter tools. Use for explicit code-based rendering or motion graphics, not ordinary generated imagery or filmed-looking video. |
| `creativeotter-setup` | Guide a first CreativeOtter connection and tour based on enabled capabilities. Use for setup, getting started or a tour; route a specific media request to its focused skill. |
| `creativeotter-submit-feedback` | Send a product or media-quality report to CreativeOtter when the user explicitly asks to report it. Ordinary complaints, observed issues or praise do not authorize a report. |
| `creativeotter-swap-characters` | Swap, replace or recast the people in an existing video with CreativeOtter: put yourself, a saved Character or a photo into a TikTok, Reel, movie scene or ad while the original motion, camera, cuts and audio stay. Use for character swaps, face swaps, recasting an actor, "put me in this video", "replace her with my grandma" and multi-person swaps. Not for copying a performance into a new scene (motion transfer) or for new footage. |
