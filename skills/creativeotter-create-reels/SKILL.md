# Plan short clips from existing video

CreativeOtter adaptation, 2026-11-06. Follow [the runtime contract](references/runtime-contract.md).

CreativeOtter currently cannot import video through its image uploader, transcribe footage, cut clips, reframe or render captions. Explain the unavailable execution steps before promising finished Reels. Use only footage or transcripts the host can actually inspect; if unavailable, ask for the relevant transcript or description without pretending to have watched it.

For recommendations, select standalone moments with a hook, necessary context and payoff. Preserve meaning and chronology. Give proposed source ranges only when observed or supplied; never fabricate timestamps or a measured virality score. Respect the requested length, count, aspect and caption choice.

Offer an edit decision list or caption draft. Do not claim clips were rendered, captions synchronized or files saved. An independently available host editor is not a CreativeOtter billed processing route. New footage and paid still-image substitutes are outside this request.
