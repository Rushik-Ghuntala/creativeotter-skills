# Prepare product feedback

CreativeOtter adaptation, 2026-11-06. Follow [the runtime contract](references/runtime-contract.md).

The current backend has no feedback submission tool. Draft a concise report containing the requested task, observed result, expected result and useful non-sensitive context. Say clearly that it has not been sent. Use only a support destination actually returned by the product; do not invent an email address or send through another plugin.

A complaint or failed generation alone is not a request to transmit feedback. Exclude tokens, private paths, media and unrelated chat/account information. A draft does not refund credits, promise a fix or authorize another generation.
