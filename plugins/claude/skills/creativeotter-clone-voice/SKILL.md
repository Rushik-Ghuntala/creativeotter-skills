# Prepare a consented voice project

CreativeOtter adaptation, 2026-11-06. Follow [the runtime contract](references/runtime-contract.md).

CreativeOtter currently has no voice-cloning service, audio import flow or synthesis billing. Explain that limitation before requesting a sample. Do not use private image upload tools for audio, ask for microphone access, collect a recording through an unsupported flow or call a different service.

Discuss only the user's own voice or a speaker who explicitly authorized this use. If the user requests preparation, help draft the script, desired language and delivery. Saving voice direction uses `manage_voice_presets` with the fields in [Studio records](references/studio-records.md); it is not consent capture, a clone or an audio file. Do not invent consent text, provider identities or policy URLs.
